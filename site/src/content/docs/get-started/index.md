This section takes you from nothing installed to a mod you can see in the game. It assumes you know C# and have played Final Fantasy X up to Besaid, the island the game reaches about an hour and a half in. It assumes nothing about ATEL or FFX modding.

Go through the pages in this order:

1. [Requirements](/ffx-atel-sharp/get-started/requirements/). The game, Fahrenheit with the Atel# loader, and the .NET SDK.
2. [Install](/ffx-atel-sharp/get-started/install/). The `atel` command, the project template, and the editor extensions if you want them.
3. [Quickstart](/ffx-atel-sharp/get-started/quickstart/). Make Wakka twice his size in Besaid village. Five commands and three lines of C#, with no explanation beyond what each step does.
4. [Your first mod](/ffx-atel-sharp/get-started/first-mod/). A tougher Dingo on the path outside the village, one step per page, with the reasons behind each step.

After that, the [guides](/ffx-atel-sharp/guides/) add one mod each on the same island, and [Concepts](/ffx-atel-sharp/concepts/) explains the script machine the mods run on.
