Atel# is an open source project on [GitHub](https://github.com/yutamago/ffx-atel-sharp). These pages are about the project itself rather than about writing mods.

- [Changelog](/ffx-atel-sharp/project/changelog/): what changed in each release.
- [Releases and versions](/ffx-atel-sharp/project/releases/): the packages, where to get them, and how versions work.
- [Contributing](/ffx-atel-sharp/project/contributing/): how to build Atel#, run the tests, and send a change.
- [Licence](/ffx-atel-sharp/project/licence/): MIT, for Atel# and by default for the mods you make with it.
