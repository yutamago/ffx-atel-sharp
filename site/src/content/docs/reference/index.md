The reference is where you look things up once you know how a mod is put together.

- [Game library API](/ffx-atel-sharp/reference/api/): the classes, members and attributes your mod's C# uses, starting with the ones you need most.
- [CLI](/ffx-atel-sharp/reference/cli/): every `atel` command, what it does and when you use it.
- [Language](/ffx-atel-sharp/reference/language/): which C# Atel accepts, and what each construct does in the game.
- [Analyzers](/ffx-atel-sharp/reference/analyzers/): one page per `ATL` rule, with an example that breaks it and the fix. The link on a rule in your editor opens its page.
