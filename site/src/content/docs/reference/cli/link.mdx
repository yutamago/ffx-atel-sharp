`atel link` does on your machine what the loader does when the game starts. It links one or more mod packages onto the game's own script files, writes the linked files to a folder and prints what each mod changed.

Use it to check a mod, or two mods together, before you start the game. It links the mods in the order you give them.

Nothing it writes is needed to play: the loader links again at every start, from the player's own game files.

## Usage

<CliUsage command="link" />

## Example

```bash
atel link my-mod/bin/Debug/net10.0/mods/my.mod -o linked
```
