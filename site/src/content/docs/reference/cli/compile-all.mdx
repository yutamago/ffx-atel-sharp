<Aside title="For contributors">
You don't need this command to write a mod. It is part of the work on Atel# itself.
</Aside>

`atel compile-all` compiles every script folder of a decompiled tree and compares each with the game's file. It lists the scripts that differ and those the tree lacks.

It checks a whole source tree at once, such as the source repository after a change to its names or its library classes.

## Usage

<CliUsage command="compile-all" />

## Example

```bash
atel compile-all src --check
```
