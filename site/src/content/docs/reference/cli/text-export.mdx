`atel text export` writes the game's messages, the lines of dialogue and the other texts the scripts show, as JSON files next to your decompiled source. The editor extensions read them and show a message's text where the code says `Text[12]`.

Run it after `atel decompile`, with the same `-o` folder. Without script names it exports every event and battle script. Without `--lang` it exports every language.

The files are the game's text: they stay on your machine. Don't commit or share them.

## Usage

<CliUsage command="text-export" />

## Example

```bash
atel text export -o vanilla
atel text export bjyt0400 -o vanilla --lang en
```
