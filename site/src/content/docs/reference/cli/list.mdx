`atel list` prints the paths of the game's scripts: events, monsters and battle scripts. Give it part of a name to see fewer, such as `bjyt` or `_m209`.

Use it to find the script you pass to `atel decompile`. The last part of a path, without its extension, is the script's name.

## Usage

<CliUsage command="list" />

## Example

```bash
atel list bjyt
```
