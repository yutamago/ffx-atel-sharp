<Aside title="For contributors">
You don't need this command to write a mod. It is part of the work on Atel# itself.
</Aside>

`atel asm` reads a file in the syntax `atel disasm` writes, assembles it onto the original script and writes the whole script file. Together with `atel disasm` it lets you change a script at the level of single instructions, to test what the game does with them.

## Usage

<CliUsage command="asm" />

## Example

```bash
atel disasm m209 -o m209.asm
atel asm m209 m209.asm -o m209.bin
```
