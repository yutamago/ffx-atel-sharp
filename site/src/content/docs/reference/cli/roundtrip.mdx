<Aside title="For contributors">
You don't need this command to write a mod. It is part of the work on Atel# itself.
</Aside>

`atel roundtrip` decompiles every script, or those whose path contains the filter, compiles each back and compares it with the game's own bytes. It is the project's main check that the compiler gives back exactly what the game shipped.

Without a filter it reads the whole game and needs several GB of memory.

## Usage

<CliUsage command="roundtrip" />

## Example

```bash
atel roundtrip bjyt
atel roundtrip --check
```
