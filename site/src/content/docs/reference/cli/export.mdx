<Aside title="For contributors">
You don't need this command to write a mod. It is part of the work on Atel# itself.
</Aside>

`atel export` decompiles every script into a git repository: the project's private source repository, which keeps the decompiled source with its hand-written names and notes. It commits the new output on one branch, merges it into the main branch and checks with `atel compile-all` that everything compiles back.

It is for the maintainers of that repository.

## Usage

<CliUsage command="export" />

## Example

```bash
atel export ~/ffx-atel-src --check
```
