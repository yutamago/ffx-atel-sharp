<Aside title="For contributors">
You don't need this command to write a mod. It is part of the work on Atel# itself.
</Aside>

`atel disasm` prints a script as ATEL assembly: the instructions the game's script machine runs, one per line.

To write a mod you read the decompiled C# instead. The assembly is for work on the decompiler and the compiler, and for checking what a piece of C# compiles to.

## Usage

<CliUsage command="disasm" />

## Example

```bash
atel disasm m209 -o m209.asm
```
