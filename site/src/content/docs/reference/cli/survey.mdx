<Aside title="For contributors">
You don't need this command to write a mod. It is part of the work on Atel# itself.
</Aside>

`atel survey` reads every script of the game and measures how the original compiler wrote them: the stack, jumps, loops, constants, workers and more. The compiler's encoding rules are based on these numbers.

It reads the whole game and needs several GB of memory.

## Usage

<CliUsage command="survey" />

## Example

```bash
atel survey -o survey.txt
```
