`atel names export` writes the game's own names for monsters, commands and items, places and battles next to your decompiled source. The editor extensions read them and show, next to a value such as `Target.…` or `Map.…` in the code, its name in the game.

It takes the same `-o` folder and `--lang` list as `atel text export`. The files are the game's text: they stay on your machine.

## Usage

<CliUsage command="names-export" />

## Example

```bash
atel names export -o vanilla
```
