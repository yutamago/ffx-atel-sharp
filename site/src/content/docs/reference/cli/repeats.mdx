<Aside title="For contributors">
You don't need this command to write a mod. It is part of the work on Atel# itself.
</Aside>

`atel repeats` finds statement sequences that recur in the game's scripts with only different values. They are the candidates for the inline helpers that make the decompiled source shorter, such as `Dialogue.Say`.

`--verify` folds the first helpers into the decompiler and checks that the bytes stay the same.

## Usage

<CliUsage command="repeats" />

## Example

```bash
atel repeats -o repeats
```
