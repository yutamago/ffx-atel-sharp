A request is called without `await` or `_ =`, so it isn't clear whether the caller should wait. Suggestion: the editor shows it, the build doesn't list it.

## What it means

A call of an `async` entry is a request. Without `await`, the request is queued and the caller goes on at once.
That is often what you want, but the call alone doesn't say so. C# gives the same hint for .NET tasks (CS4014).

## How to fix it

Say which you mean: `_ =` to queue it and go on, `await` to wait until it has ended. The editor offers both:

## When to ignore it

It does no harm: the request is queued either way. Writing `_ =` only makes your intent visible.
