`new` creates an object or a local array, and the game has neither. Error: the build fails until it is fixed.

## What it means

The game's script machine has no objects and no heap. Workers are created by the game, not by code, and arrays
are variables of the script with a fixed size. So `new` for a class, a struct, an anonymous object or a local array
has nothing to become.

## When to ignore it

Never. Note one case that is not an object: `new Vector3(x, y, z)` given to a property such as `Pos` is fine, as
the three numbers go straight to the game's function. A `Vector3` anywhere else is reported.
