A chain of calls from an entry goes more than 3 deep. Error: the build fails until it is fixed.

## What it means

The game keeps 3 return addresses per worker. Each call of a helper or a function worker uses one. So from an
entry, a helper may call a helper, which may call one more, and that is all. The message shows the chain.

<Snippet file="Analyzers/Atl3002.cs" region="bad" title="Reported" />

## How to fix it

Flatten the chain, or make the innermost methods `[Inline]`, which add no level:

Never.
