An argument of an inline method calls something, assigns or increments. Error: the build fails until it is fixed.

## What it means

An inline method's argument is put in place of its parameter, like a C macro's. So it runs wherever the
parameter is used, perhaps several times, perhaps not at all. A call or `x++` in it would run that many times.

## When to ignore it

Never. A parameter marked `[Eager]` takes a call, because it is used once at the start of the method;
`Turn.To(Common.AngleToPoint(x, z))` is fine.
