An `async` method returns `void` or a .NET task instead of the game library's `Task`. Error: the build fails until it is fixed.

## What it means

An `async` method is an entry other workers request, and its return type is the request: `Task`, or `Task<int>`
for one that gives a value, both from `Ffx.Atel`.

## When to ignore it

Never. An entry the game runs by itself, such as `Main` or an `[Entry(n)]` method, may be `async void` so that it
can await requests. That is not reported.
