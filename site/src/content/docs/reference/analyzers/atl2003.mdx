`await` is used on something that completes at once, so it waits for nothing. Suggestion: the editor shows it, the build doesn't list it.

## What it means

Only a request (and its `.Finished` or `.Started`) waits for another worker. Anything else from the game
library that C# lets you await completes at once, and the compiler drops the `await`. You'll rarely see this one.
