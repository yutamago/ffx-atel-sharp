A method calls itself, directly or through other methods. Error: the build fails until it is fixed.

## What it means

Helpers and function workers run as subroutines that share the caller's registers. They have no stack frame of
their own, so a second call of the same method would overwrite the first one's values. The message shows the
cycle.
