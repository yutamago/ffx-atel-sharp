A string is used where the game has none. Error: the build fails until it is fixed.

## What it means

The game has no strings. A line the player reads is a message of the script's table, referred to by number,
and text for yourself goes to the log through `Debug.Print`. A `string` field, local, parameter, or a string value
made anywhere else, is reported.

## When to ignore it

Never. Strings are allowed in attributes, `nameof`, and as the argument of `Debug.Print`, `Text.New` and
`Asm`.
