A mod's static constructor does something other than set starting values. Error: the build fails until it is fixed.

## What it means

A mod's static constructor is not code that runs. It lists starting values that the loader writes into the
player's file: a monster's stats and rewards, a variable's first value, an element of a table. Each line assigns a
constant to one of those. A call, a loop, a value read from a variable, or a field that isn't the script's data is
reported, with the reason in the message.
