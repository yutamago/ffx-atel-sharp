A type the game has no room for is used, such as `long` or `double`. Error: the build fails until it is fixed.

## What it means

Every value in a script is 32 bits: a whole number or a float. `long`, `ulong`, `double`, `decimal`, `char`,
`object`, `dynamic`, native-sized integers and pointers don't fit. A literal like `0.5` is a `double` in C#, so it
is reported too.
