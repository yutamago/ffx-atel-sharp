`Wait.Seconds` is given less than half a frame, a negative value, or a value too large to count. Error: the build fails until it is fixed.

## What it means

Scripts run once a frame, 30 times a second, so the shortest wait is one frame. `Wait.Seconds(s)` rounds `s`
times 30 to the nearest frame, and a value that rounds to 0 frames waits for nothing.
