A shared library class is used as a worker, but none or several of the script's workers derive from it. Error: the build fails until it is fixed.

## What it means

The decompiler keeps workers that are the same in many scripts in a `Library/` folder, and each script's worker
derives from the library class. Written in a script, the library class's name means the one worker of that script
that derives from it. When two do, as here, or none, the name means no worker.
