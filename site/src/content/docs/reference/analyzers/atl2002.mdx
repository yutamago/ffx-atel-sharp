An entry is called like a method, but it isn't declared `async Task`, so it can't be requested. Error: the build fails until it is fixed.

## What it means

Entries are not functions. Another worker runs them when it gets to them, through a request. Only an entry
declared `async Task` can be requested from code, and the call of it is the request.

## How to fix it

Declare the entry `public static async Task NameAsync()`, and request it:

## When to ignore it

Never. To run some code on your own worker right away, write a helper method instead of an entry.
