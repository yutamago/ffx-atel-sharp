A type or member of .NET is used, and .NET isn't there when the script runs. Error: the build fails until it is fixed.

## What it means

Your mod runs on the game's script machine, not on .NET. `Math`, `Console`, `Array.Length`, `GetHashCode` and
everything else from the `System` and `Microsoft` namespaces doesn't exist there.

## When to ignore it

Never. The built-in number types (`int`, `float`, `bool`, …) and constants such as `int.MaxValue` are fine, and
so are attributes and `using` lines, which only matter at build time.
