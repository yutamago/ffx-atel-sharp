A `[Saved]` field has a type, a place or a key the loader can't save. Error: the build fails until it is fixed.

## What it means

A saved field is a variable in the save game's mod area, which the loader lays out when the game starts. So it
must be a static field of a plain number type (`byte` to `int`, or `float`), or an array of one with its size,
in a static class of your mod or your part of a script class. Its key must be unique and hold no `/` or space. The
message says which rule the field breaks.
