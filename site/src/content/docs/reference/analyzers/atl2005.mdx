A worker awaits one of its own entries, which only works when the request's level is above its own. Warning: the build goes on, and the editor marks the line.

## What it means

A worker runs one request at a time per priority level. Awaiting its own entry at the level it already runs at
is refused: the entry doesn't run and the `await` returns at once. Below that level, the entry never starts and the
caller waits for ever. Only a higher level works. The analyzer can't see the levels here, so it warns.

## When to ignore it

When you request at a level you know is above the caller's (`Priority.P5` from code running at level 1), the
request runs as a call. Suppress the warning there.
