A parameter whose value is needed at build time gets a value known only at run time. Error: the build fails until it is fixed.

## What it means

`Wait.Seconds(s)` counts its frames when the mod is built, so `s` must be known then: a literal, a `const`, or
arithmetic of them. A variable or a register has no value until the script runs.
