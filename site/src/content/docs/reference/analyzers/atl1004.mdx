A collection type is used, and nothing in a script can grow. Error: the build fails until it is fixed.

## What it means

The game keeps values in variables and fixed-size arrays. `List<T>`, `Dictionary<K, V>` and the other .NET
collections need memory that grows, which a script doesn't have.
