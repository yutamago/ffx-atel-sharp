A worker waits for one of its own entries at a level where that entry can never start. Error: the build fails until it is fixed.

## What it means

A worker starts a request only when its priority level is above the level it is running at. `Init` runs at
level 7 and `Main` at level 0. So when `Init` requests one of its own worker's entries at level 7 and waits, the
request is refused at once and the entry never runs. Below the running level the request never starts, and the
caller waits for ever. A request to entry 0 never registers at all.

The rule checks the decompiler's request form, `RequestWaitEnd(level, worker, entry)`, where it knows both
levels. The worker here is worker 0 of its script:
