`+=`, `++` or another compound assignment is used on a property that is a game function. Error: the build fails until it is fixed.

## What it means

A property such as `Self.Hp`, `Yaw` or `Actors[…].Hp` is a native: reading it calls one game function,
assigning it calls another. `+=` would hide both calls in one operator, so the compiler takes only `=`.
