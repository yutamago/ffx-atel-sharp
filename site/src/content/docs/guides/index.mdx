Every guide teaches on Besaid, the island the game reaches about an hour and a half in. Each one adds a mod there that changes something you can see, and each mod is a project in the repository's [`examples/Besaid`](https://github.com/yutamago/ffx-atel-sharp/tree/main/examples/Besaid) folder.

## How every guide builds its mod

The guides build each mod the way the [Quickstart](/ffx-atel-sharp/get-started/quickstart/) did: decompile the script into `atel-vanilla/` in your mods folder, create the project with `dotnet new atel-mod`, put the guide's files in it, `dotnet build`, copy the mod folder into Fahrenheit's `mods` folder, and add its id to `mods/loadorder` below `yuta.atel`.

You can also build the examples straight from a clone of the repository, with the path to your vanilla source:

```sh
dotnet build examples/Besaid/BesaidGossip -p:AtelVanillaSource=<your atel-vanilla folder>
```

Each example's id starts with `your-name`. A Fahrenheit mod id starts with its author, so put your own name or handle in `AtelModId` and `Authors` before you share a copy.

The mods can be installed together. Three of them add to the same villager's conversation, and all three then run, one after the other, in load order.

## A save for the course

Most guides need a save in Besaid. Some of them depend on the moment in the story: the Quickstart needs the night after the trial, the camera guide the beach before the party leaves the island, and the old woman of three guides is in the village at most visits but not all. Each guide says where to go and when.
