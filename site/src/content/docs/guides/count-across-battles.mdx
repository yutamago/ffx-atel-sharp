## What you'll make

Two mods. The first, BesaidTally, counts the Dingos, Water Flans and Condors you defeat, and keeps the count with your save. Each defeat prints the new count on the screen.

The second, BesaidTallyReader, reads that count. Each time a Dingo appears, it prints how many monsters you have defeated so far.

## Where in the game

Random battles on the Village Slope and the Waterfall Way, where these three monsters live. Their scripts are `m009` for the Dingo, `m016` for the Water Flan and `m028` for the Condor.

The class is in the mod's own namespace, not in a script's. All three monster scripts use it, and it is the same field in all of them.

## Build and install

In your mods folder, with `FFX_GAME_DIR` set:

```sh
atel decompile m009 m016 m028 -o atel-vanilla
dotnet new atel-mod -n BesaidTally --script m009 --authors your-name
dotnet new atel-mod -n BesaidTallyReader --script m009 --authors your-name
```

In `BesaidTally`, replace `M009.cs` with the one above and add `M016.cs`, `M028.cs` and `Tally.cs`. In `BesaidTallyReader`, replace `M009.cs`, add `Tally.cs` and `mod.toml`, and add the `AtelModDependencies` line to the project. Wherever the reader names `your-name.besaidtally`, use the tally's real id: in the project, twice in `mod.toml`, and in `[Saved(Mod = …)]`.

Build both with `dotnet build`, copy both mod folders into Fahrenheit's `mods` folder, and list them in `mods/loadorder` in this order:

```
yuta.atel
your-name.besaidtally
your-name.besaidtallyreader
```

## What to look for

In the game:

1. Defeat a Dingo, a Water Flan or a Condor. The overlay shows `Besaid monsters defeated: 1`, and one more after each defeat.
2. With the reader installed, each Dingo that appears prints `Besaid Tally Reader: N defeated so far`.
3. Save, quit to the title, load, and fight again. The count goes on from where it was.

In Fahrenheit's log, one line per monster script, such as:

```
info: your-name.besaidtally: m009: worker 1's OnDeath: postfix Count
```

## Known limitations

These mods haven't been run in the game yet.

- They count defeated monsters, not battles. A battle count would need a change in each battle's script, a dozen of them on the island. The monster scripts are shared by all those battles, so three files cover them.
- Whether `OnDeath` runs once for every defeated monster in every case isn't known: a monster you flee from, or one an aeon finishes, may count differently.
- The tutorial battles on the island may use the game's other copies of these monsters, which these mods don't change.

## What can go wrong

- **The reader prints nothing.** Check the log: if BesaidTally isn't linked, the loader leaves the reader out. Also check that the reader's id for the tally is the tally's real id.
- **The count starts at 0 again after loading.** The saved field wasn't kept. Check the log for the tally's `saved field(s)` line.
