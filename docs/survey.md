## Constant and variable tables

The variable, integer and float tables are one set per block, shared by every worker (docs/formats/script-block.md). The models walk the workers' code in code order and give each value an index when they first meet it:

- *first use*: where it is first pushed;
- *non-negative first*: per statement (from an empty stack to the next), the non-negative values where they are pushed, then the negative ones;
- *literal, then fold*: as before, but a negative value also gives its absolute value an index where it is pushed, as a parser that numbers the literal `48.0` and then folds `-48.0` into a new constant would; indices of values that end up unused are dropped.
